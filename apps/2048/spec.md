# 2048 게임 — spec (승인본)

## 개요
방향키/스와이프로 숫자 타일을 밀어 같은 수를 합치는 4×4 퍼즐 게임. 점수판 포함. `/apps/2048/`에 순수 HTML/CSS/JS로 자체 완결.

## 사양
- **보드**: 4×4. 시작 시 임의 칸 2개에 타일(2 또는 4) 배치.
- **조작**: 데스크톱 방향키(←↑→↓), 모바일 스와이프.
- **병합**: 같은 값이 이동 방향에서 만나면 2배로 합쳐짐. 한 이동에서 한 타일은 한 번만 병합.
- **타일 생성**: 유효한 이동마다 빈 칸에 새 타일 1개(2 = 90%, 4 = 10%).
- **점수**: 현재 점수(병합 값 누적) + 최고 점수(`localStorage["2048-best"]` 저장·유지).
- **상태**: 2048 최초 생성 시 승리(계속 가능), 이동·병합 불가 시 게임오버 오버레이.
- **New Game** 버튼으로 리셋.
- 가벼운 CSS 트랜지션. 외부 라이브러리 없음.

## 파일
