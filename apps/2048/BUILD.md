## 기능 요구사항
1. **보드**: 4×4 그리드. 시작 시 임의 칸 2개에 타일(2 또는 4).
2. **조작**:
   - 데스크톱: 방향키(ArrowLeft/Up/Right/Down)로 전체 타일 이동. 화면 스크롤 방지(preventDefault).
   - 모바일: 터치 스와이프(상/하/좌/우) 감지해 동일하게 이동.
3. **병합 규칙(표준 2048)**: 이동 방향으로 밀어 같은 값이 만나면 합쳐 2배. 한 번의 이동에서 한 타일은 한 번만 병합. 이동으로 실제 변화가 있을 때만 새 타일 1개 생성(2=90%, 4=10%).
4. **점수판**:
   - 현재 점수(SCORE): 병합으로 생긴 값의 합만큼 증가.
   - 최고 점수(BEST): `localStorage["2048-best"]`에 저장, 현재 점수가 넘으면 갱신. 재방문 시 복원.
5. **상태 판정**:
   - 2048 타일 최초 생성 시 승리 메시지("You Win!"), 계속하기 허용.
   - 빈 칸 없고 어떤 방향으로도 병합 불가하면 게임오버 오버레이("Game Over").
6. **New Game 버튼**: 보드·현재 점수 초기화(최고 점수는 유지).
7. **디자인**: 깔끔한 다크 톤(블로그와 이질감 없게). 타일 값별 색상 구분. 가벼운 등장/이동 트랜지션. 모바일 폭에서도 보드가 화면을 넘치지 않게 반응형.
8. **접근성/견고성**: 콘솔 에러 없이 동작. 의미 있는 구조.
