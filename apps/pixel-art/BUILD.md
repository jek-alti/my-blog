## 기능 요구사항
1. **격자**: 16×16 셀 그리드. 셀을 클릭하면 현재 선택 색으로 칠함. 마우스 누른 채 드래그하면 지나가는 셀들이 연속으로 칠해짐.
2. **팔레트**:
   - 미리 정의된 색 약 16개(스와치 버튼). 클릭하면 현재 색으로 선택되고 선택 표시.
   - `<input type="color">`로 커스텀 색도 선택 가능.
   - 현재 선택된 색을 시각적으로 표시.
3. **도구**:
   - 지우개: 선택 시 칠하기 대신 셀을 투명(빈 칸)으로 만듦.
   - 전체 지우기(Clear): 격자 전체를 비움(확인 후).
4. **PNG 저장**:
   - 별도 `<canvas>`(표시 안 해도 됨)에 16×16 그림을 확대(도트당 20px → 320×320)로 렌더.
   - 빈 셀은 투명 유지.
   - `canvas.toDataURL('image/png')` → `<a download>`로 `pixel-art.png` 다운로드.
5. **모바일**: 터치(touchstart/move)로 그리기 지원. 그리는 동안 페이지 스크롤 방지(`touch-action:none` 등).
6. **(옵션) 저장/복원**: 현재 그림을 `localStorage`에 저장하고 재방문 시 복원(구현하면 좋음, 키는 `pixel-art-data`).
7. **디자인**: 깔끔한 다크 톤(블로그와 이질감 없게). 격자 셀 경계 표시. 반응형(모바일 폭에서 격자가 화면을 넘치지 않게, 예: `aspect-ratio` + `max-width`).
8. **견고성**: 콘솔 에러 없이 동작. 전역 오염 없이(IIFE 등) 작성.
