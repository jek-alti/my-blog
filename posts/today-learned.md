# 오늘 배운 것

클로드 코드(Claude Code)와 함께 프레임워크 없이 순수 HTML·CSS·JavaScript만으로 블로그를 만들어 봤다. 만들면서 세 가지 언어가 각각 무슨 일을 하는지 몸으로 이해하게 됐다. 오늘 배운 것을 간단히 정리한다.

## 웹페이지는 세 가지 층으로 나뉜다

웹페이지 하나는 보통 **구조 · 표현 · 동작**의 세 가지 역할로 나눠서 만든다. 각각을 HTML, CSS, JavaScript가 맡는다. 집을 짓는 데 비유하면 이해가 쉬웠다.

| 언어 | 역할 | 비유 |
| --- | --- | --- |
| HTML | 구조(내용) | 벽과 방의 뼈대 |
| CSS | 표현(디자인) | 페인트와 인테리어 |
| JavaScript | 동작(상호작용) | 전기와 스위치 |

## HTML — 구조를 만든다

HTML은 페이지에 **무엇이 있는지**를 정의한다. 제목, 문단, 목록, 링크 같은 내용의 뼈대다.

이번에 배운 핵심은 **의미에 맞는 태그를 쓰는 것**이었다. 아무 데나 `<div>`를 쓰지 않고, 역할에 맞는 태그를 골랐다.

```html
<header>사이트 제목과 메뉴</header>
<main>
  <article>글 한 편</article>
</main>
<footer>저작권 정보</footer>
```

- `<header>`, `<main>`, `<article>`, `<footer>` 처럼 뜻이 담긴 태그를 쓰면 검색엔진과 스크린 리더가 구조를 이해한다.
- 날짜는 `<time>` 태그로 감싸 기계도 읽을 수 있게 했다.

## CSS — 보기 좋게 꾸민다

CSS는 HTML로 만든 구조를 **어떻게 보이게 할지**를 정한다. 색, 글꼴, 여백, 배치가 전부 CSS의 몫이다.

가장 유용했던 건 **CSS 변수(커스텀 프로퍼티)** 였다. 색을 한 곳에 정의해 두고 여기저기서 가져다 쓰니, 다크 모드를 만들 때 값만 바꿔주면 됐다.

```css
:root {
  --bg: #fbfaf7;
  --text: #23201c;
}
:root[data-theme="dark"] {
  --bg: #16140f;
  --text: #ece7de;
}
body {
  background: var(--bg);
  color: var(--text);
}
```

- 색을 하드코딩해서 여러 곳에 반복하지 않고, 변수로 한 번만 정의한다.
- **모바일 우선**으로 먼저 좁은 화면을 잡고, 미디어 쿼리로 넓은 화면을 확장했다.
- 이미지·코드·표가 화면을 넘치지 않도록 `max-width`와 `overflow-x` 를 챙겼다.

## JavaScript — 살아 움직이게 한다

JavaScript는 페이지에 **동작**을 넣는다. 버튼 클릭에 반응하고, 파일을 불러오고, 화면을 바꾼다.

이 블로그에서 JS가 한 일은 크게 두 가지였다.

1. **마크다운 글 불러오기**: `fetch` 로 `.md` 파일을 읽어와 화면에 뿌린다.
2. **다크 모드 토글**: 버튼을 누르면 테마를 바꾸고, 선택을 `localStorage` 에 저장해 다음에 와도 유지한다.

```javascript
// 마크다운 파일을 불러와 HTML로 바꿔서 보여주기
const res = await fetch("posts/today-learned.md");
const markdown = await res.text();
document.body.innerHTML = marked.parse(markdown);
```

> 사용자가 쓴 내용을 그대로 화면에 넣으면 위험할 수 있어서, `DOMPurify` 로 한 번 걸러 XSS를 막는 것도 배웠다.

## 정리하며

세 언어는 경쟁하는 게 아니라 **역할을 나눠 맡는** 관계였다.

- **HTML**은 내용의 뼈대를 세우고,
- **CSS**는 그 위에 옷을 입히고,
- **JavaScript**는 움직임을 불어넣는다.

프레임워크 없이 만들어 보니 각 층이 무슨 일을 하는지 또렷하게 보였다. 다음엔 태그별 글 필터나 검색 같은 기능도 붙여 보고 싶다.
